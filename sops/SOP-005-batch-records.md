# SOP-005: Batch Production Records

**Document ID:** SOP-005  
**Version:** 1.0  
**Effective Date:** 14/10/2026  
**Department:** Production / Quality Assurance

---

## 1. PURPOSE

To ensure all batch production activities are documented completely and accurately to provide a full history of batch manufacture.

## 2. SCOPE

All cultivation batches from seed/clone receipt through final packaging.

## 3. PROCEDURE

### 3.1 Batch Record Contents

Each batch record must include:
- Batch number (format: BTH-YYYY-####)
- Strain/cultivar name and ID
- Date of initiation
- Mother plant ID (if clone) or seed lot number
- All processing steps with dates, times, and operator initials
- Environmental data summaries
- Deviation references (if any)
- Yield calculations
- QA release signature

### 3.2 Data Entry Requirements

- **Real-time entry:** Record data at time of activity, not retrospectively
- **Permanent ink:** No pencil, no erasable ink
- **Corrections:** Single line through error, initial and date, then correct entry
- **No blank spaces:** N/A or line through unused sections
- **Signatures:** Full signature and date for each critical step

### 3.3 Batch Numbering System

Format: `BTH-YYYY-####`
- BTH = Batch
- YYYY = Year
- #### = Sequential number (0001, 0002, etc.)

Example: BTH-2026-0001
