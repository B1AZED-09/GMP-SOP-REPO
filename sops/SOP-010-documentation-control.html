# SOP-010: Document Control **Document ID:** SOP-010 **Version:** 1.0 **Effective Date:** 14/10/2026 **Department:** Quality Assurance --- ## 1. PURPOSE To ensure all GMP documents are controlled, current, and available to prevent use of obsolete or unauthorized documents. ## 2. SCOPE All SOPs, batch records, specifications, and controlled forms. ## 3. PROCEDURE ### 3.1 Document Numbering System Format: `XXX-NNN` - XXX = Document type (SOP, BTH, SPEC, FORM) - NNN = Sequential number Example: SOP-001, BTH-2026-0001 ### 3.2 Version Control - Draft versions: 0.1, 0.2, 0.3 (for review) - Approved versions: 1.0, 2.0, etc. (major changes) - Minor revisions: 1.1, 1.2 (typo corrections) ### 3.3 Document Approval All GMP documents must be approved by: 1. Author (subject matter expert) 2. QA Manager (compliance) 3. Department Manager (operational feasibility) ### 3.4 Distribution and Retrieval - **Master copies:** Stored in QA office (locked cabinet) - **Controlled copies:** Issued to departments with copy number stamped - **Obsolete documents:** Removed immediately, archived for 5 years ### 3.5 Periodic Review All documents reviewed every 12 months or when: - Regulations change - Equipment/process changes - Deviations indicate document inadequacy ## 4. REFERENCES - EU GMP Chapter 4: Documentation - ISO 9001:2015 Section 7.5: Documented Information ## 5.
