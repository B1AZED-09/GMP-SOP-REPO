# SOP-007: Integrated Pest Management (IPM)

**Document ID:** SOP-007  
**Version:** 1.0  
**Effective Date:** 14/10/2026  
**Department:** Cultivation / Quality Assurance

---

## 1. PURPOSE

To prevent, monitor, and control pest infestations using an integrated approach that minimizes chemical pesticide use and ensures product safety.

## 2. SCOPE

All cultivation areas, propagation rooms, drying rooms, and storage areas.

## 3. PROCEDURE

### 3.1 Prevention

- Facility perimeter maintained pest-free (no standing water, vegetation trimmed)
- Air curtains/positive pressure on all external doors
- All incoming plant material quarantined for minimum 72 hours
- Staff hygiene: clean clothing, no outdoor clothing in grow rooms

### 3.2 Monitoring

| Method | Frequency | Target Pests |
|--------|-----------|--------------|
| Yellow sticky cards | Weekly review, replace monthly | Fungus gnats, whiteflies, aphids |
| Blue sticky cards | Weekly review | Thrips |
| Scope inspection | Weekly | Spider mites, eggs |
| Trap crops | Continuous | Early warning indicator |

### 3.3 Control Methods (Hierarchy)

1. **Cultural:** Environmental control (lower RH for fungus gnats), sanitation
2. **Mechanical:** Sticky cards, vacuuming, hand removal
3. **Biological:** Predatory mites (Phytoseiulus persimilis for spider mites), nematodes (Steinernema feltiae for fungus gnats)
4. **Chemical (last resort):** Only approved products, apply during dark cycle, document per SOP-003

### 3.4 Action Thresholds

| Pest | Action Threshold | Response |
|------|------------------|----------|
| Spider mites | Any live mites | Immediate biological control release |
| Fungus gnats | >10 per sticky card per week | Nematode drench, reduce watering |
| Thrips | Any detected | Sticky cards, predatory mites |
| Powdery mildew | Any visual detection | Remove affected leaves, sulfur burner, increase airflow |

## 4. REFERENCES

- EMA GACP Guideline: Section 7.4 (Plant Protection)
- Health Canada Cannabis Regulations: Section 63 (Pest Control Products)
